## Features

- A homepage with hero, services, about, testimonials, gallery, and contact
  sections
- A **services page** with cuts, colour, keratin treatments, bridal packages,
  and more
- **Online booking** with appointments stored in **Firebase**
- An **admin panel**, behind an access screen, for managing bookings
- **Installable PWA** for both the site and the admin

## Tech stack

HTML, CSS, and vanilla JavaScript, with Firebase for data and a web manifest and
service worker for the PWA.

## Project structure

```
index.html, services.html      public site
booking.html / booking.js      booking flow
admin.html / admin.js          admin panel
pwa.js, sw.js, manifest*.json  PWA setup
```

## Run locally

```bash
git clone https://github.com/dean1234533/Hair-Beauty.git
cd Hair-Beauty
npx serve .
```
